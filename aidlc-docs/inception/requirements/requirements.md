## 4. 기능 요구사항 (Functional Requirements)

### 4.1 고객용 기능 (Customer Features)

**FR-C1. 테이블 태블릿 자동 로그인 및 세션 관리**
- 관리자가 1회 초기 설정: 매장 식별자, 테이블 번호, 테이블 비밀번호 입력 후 로컬 저장
- 1회 로그인 성공 후 저장된 정보로 자동 로그인

**FR-C2. 메뉴 조회 및 탐색**
- 메뉴 화면이 기본 화면으로 항상 표시
- 카테고리별 분류 및 카테고리 간 빠른 이동
- 메뉴 상세: 메뉴명, 가격, 설명, 이미지(외부 URL)
- 카드 레이아웃, 터치 친화적 버튼(최소 44×44px)

**FR-C3. 장바구니 관리**
- 메뉴 추가/삭제, 수량 증감, 총 금액 실시간 계산, 장바구니 비우기
- 클라이언트 측 로컬 저장 (페이지 새로고침 시에도 유지)
- 서버 전송은 주문 확정 시에만 수행

**FR-C4. 주문 생성**
- 주문 내역 최종 확인 및 주문 확정
- 성공 플로우: 주문 번호 표시 → 장바구니 자동 비우기 → 메뉴 화면 자동 리다이렉트 (5초 표시 후)
- 실패 시: 에러 메시지 표시 + 장바구니 유지
- 주문 정보: 매장 식별, 테이블 식별, 메뉴 목록(메뉴명/수량/단가), 총 금액, 세션 ID

**FR-C5. 주문 내역 조회**
- 주문 시간 순 정렬, 주문별 상세(주문 번호/시각/메뉴·수량/금액/상태)
- 상태: 대기중 / 준비중 / 완료
- **현재 테이블 세션 주문만 표시** (이전 세션·이용 완료분 제외)
- 페이지네이션 또는 무한 스크롤

### 4.2 관리자용 기능 (Admin Features)

**FR-A1. 매장 인증**
- 매장 식별자 + 사용자명 + 비밀번호 입력
- JWT 토큰 기반 인증, 16시간 세션 유지, 새로고침 시 유지, 16시간 후 자동 로그아웃
- 비밀번호 bcrypt 해싱, 로그인 시도 제한

**FR-A2. 실시간 주문 모니터링**
- **Server-Sent Events(SSE)** 기반 실시간 업데이트, 2초 이내 주문 표시
- 그리드/대시보드 레이아웃: 테이블별 카드, 총 주문액, 최신 주문 n개 미리보기
- 주문 카드 클릭 시 전체 메뉴 목록 상세 보기
- 주문 상태 변경(대기중/준비중/완료), 신규 주문 시각적 강조
- 테이블별 필터링

**FR-A3. 테이블 관리**
- 테이블 태블릿 초기 설정(테이블 번호/비밀번호, 16시간 세션 생성, 자동 로그인 활성화)
- 주문 삭제(직권 수정): 확인 팝업 → 즉시 삭제 → 총 주문액 재계산 → 피드백
- 테이블 세션 처리: 세션 시작(첫 주문)~종료(이용 완료) 관리
  - 이용 완료 시 해당 세션 주문을 과거 이력으로 이동
  - 현재 주문 목록 및 총 주문액 0으로 리셋
  - 새 고객이 이전 이력 없이 시작 가능
- 과거 주문 내역 조회: 테이블별 시간 역순 목록, 주문 상세(번호/시각/메뉴/금액/이용완료 시각), 날짜 필터

**FR-A4. 메뉴 관리**
- 메뉴 조회(카테고리별), 등록(메뉴명/가격/설명/카테고리/이미지 URL), 수정, 삭제, 노출 순서 조정
- 데이터 검증: 필수 필드, 가격 범위

### 4.3 데이터 시딩 (Seed Data)
- **SD-1**: 샘플 매장 1개 + 관리자 계정(bcrypt 해싱된 비밀번호) 시드
- **SD-2**: 샘플 메뉴 데이터(카테고리별) + 외부 이미지 URL 시드
- **SD-3**: 테이블 10~20개 초기 설정 데이터

## 7. 용어 정의
- **MVP**: Minimum Viable Product
- **테이블 세션**: 특정 테이블에서 고객이 첫 주문을 시작한 시점부터 이용 완료 처리까지의 기간. 종료 후 다른 고객의 첫 주문 시 새 세션 시작.
- **SSE**: Server-Sent Events (서버→클라이언트 단방향 실시간 스트림)
- **PBT**: Property-Based Testing (속성 기반 테스트)

## 8. 핵심 요구사항 요약
테이블오더 MVP는 **고객용 웹 UI**(자동 로그인, 메뉴 조회, 로컬 장바구니, 주문 생성, 현재 세션 주문 조회)와 **관리자용 웹 UI**(16시간 JWT 세션 인증, SSE 실시간 주문 모니터링, 테이블/세션 라이프사이클 관리, 메뉴 관리)를 **React(Vite) + FastAPI + SQLite** 스택으로 구현합니다. 로컬 실행을 목표로 하며, 샘플 시드 데이터로 즉시 구동 가능하게 합니다. 속성 기반 테스트를 전체 적용하되, 검증 가치가 높은 영역(주문 금액 계산, 장바구니 상태, 세션/주문 상태 전이)에 집중합니다.
